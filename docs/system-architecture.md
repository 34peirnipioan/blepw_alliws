# System Architecture

## 🦯 Smart Cane Architecture

Ultrasonic Sensor → Arduino UNO → Buzzer Alert

The smart cane detects obstacles in front of the user and produces an audio warning when an object is detected within a predefined distance.

---

## 👟 Smart Shoes Architecture

Ground Sensor → Arduino UNO → Audio

The smart shoes detect stairs, gaps, or sudden floor height changes and notify the user for safer movement.

---

## ⚡ Hardware Components

- Arduino UNO
- HC-SR04 Ultrasonic Sensors
- Buzzers
- Jumper Wires
- Battery Packs
- Wearable Prototype Materials
